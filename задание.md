# Техническое задание на разработку компонента CM Data Grid (самостоятельная реализация на JavaScript и jQuery)

## 1. Общее описание

**CM Data Grid** — это универсальный, полностью самостоятельный компонент для отображения и управления табличными данными, реализованный на чистом JavaScript с использованием jQuery. Компонент не зависит от сторонних библиотек для работы с таблицами и предоставляет весь необходимый функционал для корпоративных веб-приложений.

---

## 2. Архитектура и структура

### 2.1. Технологический стек
- **JavaScript ES6+** — логика компонента
- **jQuery 3.x** — для упрощения работы с DOM, событиями и AJAX
- **CSS3** — стилизация компонента (использование CSS-переменных для тем)
- **HTML5** — структура компонента

### 2.2. Поддерживаемые браузеры
- Chrome (последние 2 версии)
- Firefox (последние 2 версии)
- Safari (последние 2 версии)

- Internet Explorer 11 (с полифиллами)

## 3. Функциональные требования

### 3.1. Источник данных (DataSource)

**3.1.1. Типы источников данных**
- **Локальный массив** — данные передаются напрямую
- **Удаленный источник** — данные загружаются через AJAX
- **Функция-источник** — пользовательская функция, возвращающая данные

**3.1.2. Структура DataSource**

```javascript
{
    // Конфигурация DataSource
    data: [],                    // Массив данных (для локального источника)
    transport: {                 // Для удаленного источника
        read: {
            url: '/api/data',
            type: 'GET',
            dataType: 'json',
            data: {}              // Дополнительные параметры запроса
        },
        create: { ... },         // Для операций создания
        update: { ... },         // Для операций обновления
        destroy: { ... }         // Для операций удаления
    },
    schema: {                    // Схема данных
        data: 'data',            // Путь к массиву данных в ответе
        total: 'total',          // Путь к общему количеству записей
        model: {                 // Модель записи
            id: 'id',
            fields: {
                name: { type: 'string' },
                age: { type: 'number' },
                // ...
            }
        }
    },
    pageSize: 20,               // Размер страницы
    serverPaging: false,         // Серверная пагинация
    serverSorting: false,        // Серверная сортировка
    serverFiltering: false,      // Серверная фильтрация
    serverGrouping: false,       // Серверная группировка
    sort: [{ field: 'name', dir: 'asc' }],  // Начальная сортировка
    filter: { logic: 'and', filters: [...] }, // Начальная фильтрация
    group: [{ field: 'category' }], // Начальная группировка
    aggregates: [               // Агрегатные функции
        { field: 'price', aggregate: 'sum' }
    ]
}
```

**3.1.3. Методы DataSource**
- `read()` — загрузка/обновление данных
- `add(dataItem)` — добавление записи
- `remove(dataItem)` — удаление записи
- `update(dataItem)` — обновление записи
- `sync()` — синхронизация изменений с сервером
- `total()` — общее количество записей
- `view()` — текущее представление данных
- `page(pageNumber)` — переход на страницу
- `sort(sortExpression)` — сортировка
- `filter(filterExpression)` — фильтрация
- `group(groupExpression)` — группировка

### 3.2. Колонки (Columns)

**3.2.1. Конфигурация колонки**

```javascript
columns: [
    {
        field: 'firstName',          // Поле данных
        title: 'Имя',                // Заголовок
        width: 150,                  // Ширина (px или %)
        minWidth: 50,                // Минимальная ширина
        maxWidth: 300,               // Максимальная ширина
        sortable: true,              // Сортировка
        filterable: true,            // Фильтрация
        groupable: true,             // Группировка
        resizable: true,             // Изменение размера
        reorderable: true,           // Переупорядочивание
        locked: false,               // Закрепленная колонка
        hidden: false,               // Скрытая колонка
        editable: true,              // Редактируемая
        template: function(data) {   // Шаблон ячейки
            return `<strong>${data.firstName}</strong>`;
        },
        editor: function(container, options) { // Редактор
            $('<input type="text" />')
                .appendTo(container)
                .val(options.value)
                .on('change', function() {
                    options.setValue($(this).val());
                });
        },
        format: '{0:yyyy-MM-dd}',    // Формат данных
        attributes: { style: 'color: red;' }, // Атрибуты ячейки
        headerAttributes: { style: 'background: #f0f0f0;' },
        footerTemplate: function(data) { // Шаблон подвала
            return `Итого: ${data.sum}`;
        },
        aggregates: ['sum', 'count'] // Агрегации для колонки
    },
    // Группа колонок (multicolumn headers)
    {
        title: 'Адрес',
        columns: [
            { field: 'city', title: 'Город' },
            { field: 'street', title: 'Улица' }
        ]
    }
]
```

**3.2.2. Операции с колонками**
- Изменение размера (resize) с сохранением пропорций
- Переупорядочивание (reorder) через drag-and-drop
- Закрепление (lock) колонок слева и справа
- Скрытие/отображение колонок через контекстное меню
- Автоматическая подгонка ширины под содержимое

### 3.3. Пагинация (Paging)

**3.3.1. Функционал пагинации**
- Разбивка данных на страницы
- Настройка размера страницы (pageSize)
- Отображение информации: "Записи X-Y из Z"
- Навигация: первая, предыдущая, следующая, последняя страница
- Переход к конкретной странице
- Выбор размера страницы из выпадающего списка (10, 20, 50, 100, Все)
- Поддержка серверной пагинации

**3.3.2. Внешний вид пагинации**
- Настраиваемый шаблон панели пагинации
- Отображение общего количества записей
- Отображение текущей страницы и общего количества страниц

```javascript
pageable: {
    pageSize: 20,
    pageSizes: [10, 20, 50, 100],
    buttonCount: 5,           // Количество отображаемых кнопок страниц
    info: true,               // Отображение информации
    numeric: true,            // Отображение числовых кнопок
    previousNext: true,       // Кнопки "Предыдущая"/"Следующая"
    messages: {
        display: 'Записи {0}-{1} из {2}',
        empty: 'Нет записей',
        page: 'Страница',
        of: 'из',
        itemsPerPage: 'записей на странице',
        first: 'Первая',
        previous: 'Предыдущая',
        next: 'Следующая',
        last: 'Последняя'
    }
}
```

### 3.4. Сортировка (Sorting)

**3.4.1. Возможности сортировки**
- Одноколоночная и многоколоночная сортировка
- Сортировка по возрастанию/убыванию
- Визуальные индикаторы направления сортировки
- Поддержка серверной сортировки
- Настраиваемые функции сравнения

```javascript
sortable: {
    mode: 'multiple',          // 'single' или 'multiple'
    allowUnsort: true,         // Возможность отмены сортировки
    showIndexes: true,         // Отображение индексов сортировки
    initial: [                // Начальная сортировка
        { field: 'name', dir: 'asc' }
    ]
}
```

### 3.5. Фильтрация (Filtering)

**3.5.1. Режимы фильтрации**
- **Фильтр через меню** — выпадающее меню с условиями
- **Фильтр в строке заголовка** — поля ввода в заголовках
- **Excel-подобный фильтр** — чекбоксы со значениями из колонки
- **Внешние фильтры** — фильтры, расположенные вне Grid

**3.5.2. Типы фильтров**
- Текстовые: содержит, не содержит, равно, не равно, начинается с, заканчивается
- Числовые: равно, не равно, больше, больше или равно, меньше, меньше или равно
- Дата: равно, до, после, между
- Булевы: равно true/false

**3.5.3. Конфигурация**

```javascript
filterable: {
    mode: 'menu',              // 'menu', 'row', 'excel', 'custom'
    operators: {
        string: {
            contains: 'Содержит',
            eq: 'Равно',
            neq: 'Не равно',
            startswith: 'Начинается с',
            endswith: 'Заканчивается'
        },
        number: {
            eq: 'Равно',
            neq: 'Не равно',
            gt: 'Больше',
            gte: 'Больше или равно',
            lt: 'Меньше',
            lte: 'Меньше или равно'
        }
    },
    extra: false,              // Отображение дополнительных условий
    applyButton: true,         // Кнопка "Применить"
    clearButton: true          // Кнопка "Очистить"
}
```

### 3.6. Группировка (Grouping)

**3.6.1. Возможности группировки**
- Группировка по одному или нескольким полям
- Отображение промежуточных итогов
- Drag-and-drop заголовков для группировки
- Разворачивание/сворачивание групп
- Поддержка серверной группировки
- Группировка с агрегациями

**3.6.2. Агрегатные функции**
- `count` — количество записей в группе
- `sum` — сумма значений
- `avg` — среднее значение
- `min` — минимальное значение
- `max` — максимальное значение
- `custom` — пользовательская функция

```javascript
groupable: {
    enabled: true,
    showFooter: true,          // Отображение подвала группы
    aggregates: ['sum', 'count'],
    messages: {
        empty: 'Перетащите сюда заголовок для группировки',
        group: 'Группировка по {0}'
    }
}
```

### 3.7. Редактирование (Editing)

**3.7.1. Режимы редактирования**

| Режим | Описание |
|-------|----------|
| `inline` | Редактирование всей строки (переключение строки в режим редактирования) |
| `popup` | Редактирование во всплывающем окне (модальное окно) |
| `incell` | Редактирование ячейки (двойной клик или Enter для редактирования) |
| `batch` | Пакетное редактирование (изменения сохраняются пакетно) |

**3.7.2. Встроенные редакторы**
- `text` — текстовое поле
- `number` — числовое поле с валидацией
- `date` — календарь (DatePicker)
- `datetime` — дата и время
- `time` — время
- `select` — выпадающий список
- `checkbox` — чекбокс для булевых значений
- `custom` — пользовательский редактор

**3.7.3. Валидация**
- Встроенные валидаторы: required, min, max, maxLength, pattern
- Настраиваемые сообщения об ошибках
- Визуальная индикация ошибок
- Блокировка сохранения при наличии ошибок

**3.7.4. Конфигурация**

```javascript
editable: {
    mode: 'popup',              // 'inline', 'popup', 'incell', 'batch'
    createAt: 'bottom',         // 'top', 'bottom'
    confirmation: true,         // Подтверждение удаления
    confirmationMessage: 'Вы уверены, что хотите удалить запись?',
    validation: {
        rules: {
            required: function(input) {
                return input.val() !== '';
            }
        },
        messages: {
            required: 'Поле обязательно для заполнения'
        }
    },
    template: function(data) {  // Шаблон формы редактирования
        return `<div>...</div>`;
    }
}
```

### 3.8. Выборка (Selection)

**3.8.1. Режимы выборки**
- `none` — выборка отключена
- `single` — выборка одной строки
- `multiple` — выборка нескольких строк
- `cell` — выборка ячейки
- `multipleCell` — выборка нескольких ячеек

**3.8.2. Функционал выборки**
- Выборка по клику на строку
- Выборка через колонку с чекбоксами
- Возможность программной установки выборки
- События при изменении выборки
- Методы для получения выбранных данных

```javascript
selectable: {
    mode: 'multiple',
    checkbox: true,             // Колонка с чекбоксами
    persistent: true            // Сохранение выборки после обновления данных
}
```

### 3.9. Виртуализация (Virtual Scrolling)

**3.9.1. Функционал виртуализации**
- Рендеринг только видимой части строк
- Рендеринг только видимых колонок (горизонтальная виртуализация)
- Автоматическая загрузка данных при прокрутке
- Поддержка серверной загрузки по требованию
- Плавная прокрутка

```javascript
virtualScroll: {
    enabled: true,
    bufferSize: 20,             // Количество дополнительных записей за пределами экрана
    pageSize: 50,               // Размер страницы для виртуализации
    threshold: 100,             // Порог для включения виртуализации (количество записей)
    mode: 'infinite'            // 'infinite' | 'virtual'
}
```

### 3.11. Иерархические данные (Hierarchical)

**3.11.1. Master-Detail**

- Использование шаблонов для отображения деталей
- Разворачивание/сворачивание дочерних строк
- Поддержка многоуровневой иерархии

```javascript
detail: {

        return `<div class="child-grid" data-parent-id="${dataItem.id}"></div>`;
    },
    init: function(element, dataItem) {

        });

```

**3.12.2. Механизмы сохранения**


## 5. Работа с событиями

### 5.1. Система событий

Компонент должен использовать собственную систему событий (EventEmitter) для подписки и публикации событий.

### 5.2. Список событий

| Событие | Описание | Параметры |
|---------|----------|-----------|
| `beforeInit` | Перед инициализацией | `config` |
| `afterInit` | После инициализации | `grid` |
| `dataBinding` | Перед привязкой данных | `dataSource` |
| `dataBound` | После привязки данных | `dataSource`, `view` |
| `change` | Изменение выборки | `selectedItems` |
| `rowClick` | Клик по строке | `row`, `dataItem` |
| `rowDblClick` | Двойной клик по строке | `row`, `dataItem` |
| `cellClick` | Клик по ячейке | `cell`, `column`, `dataItem` |
| `sort` | Применение сортировки | `sortExpression` |
| `filter` | Применение фильтрации | `filterExpression` |
| `group` | Применение группировки | `groupExpression` |
| `pageChange` | Изменение страницы | `page`, `pageSize` |
| `columnResize` | Изменение размера колонки | `column`, `newWidth` |
| `columnReorder` | Переупорядочивание колонок | `column`, `newIndex` |
| `columnShow` | Отображение колонки | `column` |
| `columnHide` | Скрытие колонки | `column` |
| `edit` | Начало редактирования | `dataItem`, `column` |
| `save` | Сохранение изменений | `dataItem`, `originalData` |
| `remove` | Удаление записи | `dataItem` |
| `create` | Создание новой записи | `dataItem` |
| `error` | Ошибка | `error`, `operation` |
| `stateLoad` | Загрузка состояния | `state` |
| `stateSave` | Сохранение состояния | `state` |
| `destroy` | Уничтожение компонента | `grid` |

### 5.3. Подписка на события

```javascript
// Через конфигурацию
$('#grid').cmDataGrid({
    dataBound: function(e) {
        console.log('Данные загружены', e);
    },
    on: {
        change: function(e) {
            console.log('Выбраны:', e.selectedItems);
        }
    }
});

// Через API
const grid = $('#grid').data('cmDataGrid');
grid.on('dataBound', function(e) {
    // Обработчик
});
grid.off('dataBound'); // Отписка
```

### 9.1. Стандарты
- Соответствие **WCAG 2.1 AA**

- Соответствие **Section 508**

### 9.2. Клавиатурная навигация

| Клавиша | Действие |
|---------|----------|
| `Tab` | Перемещение между колонками в строке |
| `Enter` | Редактирование ячейки/строки |
| `Escape` | Отмена редактирования |
| `Space` | Выборка строки/ячейки |
| `Ctrl+A` | Выбор всех строк |
| `Shift+↑/↓` | Расширение выборки |
| `↑/↓` | Перемещение между строками |
| `←/→` | Перемещение между ячейками |
| `PageUp/PageDown` | Переключение страниц |
| `Home/End` | Переход в начало/конец |

### 9.3. ARIA-атрибуты
- `role="grid"` — основная роль компонента
- `role="rowgroup"` — группа строк
- `role="row"` — строка
- `role="gridcell"` — ячейка
- `role="columnheader"` — заголовок колонки
- `aria-sort` — направление сортировки
- `aria-selected` — состояние выборки
- `aria-expanded` — состояние развернутости (для группировки)
- `aria-controls` — связь между элементами
